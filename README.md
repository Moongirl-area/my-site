# سودپز

پوسته‌ی وردپرس سایت [soodpaz.com](https://soodpaz.com). بپز، بفروش، ضرر نکن.

## ساختار

- `theme/` همه‌ی فایل‌های پوسته. هر تغییری که روی شاخه‌ی `main` پوش شود، خودکار با FTPS در `public_html/wp-content/themes/soodpaz` روی هاست آپلود می‌شود.
- `.github/workflows/deploy.yml` آپلود خودکار. اطلاعات FTP در Secretهای ریپو است (`FTP_SERVER`، `FTP_USERNAME`، `FTP_PASSWORD`).

## صفحه‌ها

| نامک | فایل | محتوا |
|---|---|---|
| (صفحه‌ی اول) | `front-page.php` | معرفی |
| `calculator` | `page-calculator.php` | ماشین‌حساب رایگان قیمت کیک |
| `pricing` | `page-pricing.php` | قیمت‌ها |
| `founders` | `page-founders.php` | پیش‌فروش عضو بنیان‌گذار |
| `learn` | `page-learn.php` | فهرست آموزش‌ها (همه‌ی نوشته‌های منتشرشده) |
| `faq` | `page-faq.php` | سؤال‌های رایج (با داده‌ی ساختاریافته برای گوگل) |
| `about` | `page-about.php` | درباره‌ی سودپز |
| `contact` | `page-contact.php` | فرم تماس |
| `privacy` | `page-privacy.php` | حریم خصوصی |
| `terms` | `page-terms.php` | قوانین و مقررات |

صفحه‌هایی که وجود ندارند و سه آموزش اول، بعد از هر آپلود خودکار ساخته می‌شوند (`inc/content.php`). چیزی که در پیشخوان ویرایش یا پاک کنی، دوباره ساخته یا بازنویسی نمی‌شود. متنی که در پیشخوان به صفحه‌های درباره، تماس و قوانین اضافه کنی، پایین متن ثابت همان صفحه نمایش داده می‌شود.

## کارهای هفتگی در پیشخوان وردپرس

منوی **سودپز**:
- قیمت مرجع مواد و تاریخش
- دستمزد، هزینه‌ی فر، بسته‌بندی و درصد سود پیش‌فرض ماشین‌حساب
- تعداد واقعی جای خالی بنیان‌گذار (خالی = نمایش داده نمی‌شود)
- **درخواست‌ها**: فرم‌های بنیان‌گذار
- **پیام‌ها**: فرم تماس

## اگر آپلود خودکار کار نکرد

در تب Actions گیت‌هاب، آخرین اجرا را باز کن و فایل `soodpaz-theme` را از پایین صفحه دانلود کن. zip داخلش را از پیشخوان وردپرس ← نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته آپلود کن.
